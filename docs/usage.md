# DeepSeek 网页翻译 · Edge 扩展使用说明

> 版本 **v1.3.1**（Manifest V3）｜逐段中英对照翻译 + 文献整理记笔记 + 侧边查词框，全部走你自己的 DeepSeek API Key。
> 扩展使用自备 API Key。设置和缓存保存在本机，翻译与文献整理请求发往配置的 API 地址。

---

## 一、这是什么

一个装在 Microsoft Edge 里的翻译扩展，三件事：

| 功能 | 一句话 | 入口 |
| --- | --- | --- |
| **网页翻译** | 把网页逐段翻成中文，译文贴在每段原文下方，中英对照 | 页面右侧「**译**」按钮 / 工具栏图标 / `Alt`+`T` / 右键菜单 |
| **文献整理** | 根据网页中可提取的正文，整理出思路·方法·内容·结论·关键数据，让你勾选、随手改、贴截图，导出成 Markdown 笔记 | 页面右侧「**摘**」按钮 / 右键菜单 |
| **侧边翻译框** | 查单词（音标+词性+释义）或粘贴句子翻译，结果一键复制 | 页面右侧「**文**」按钮 |

三个按钮都贴在网页右边缘、可以上下拖动，位置会记住。

## 二、安装（三步）

1. 下载并解压 `deepseek-web-translator-1.3.1.zip`，放到固定位置，例如 `E:\Tools\deepseek-web-translator`。
   要求：解压后**直接就能看到 `manifest.json`** 的那一层（不要多套一层文件夹）。
2. 地址栏打开 `edge://extensions/` → 打开右下角「**开发人员模式**」→ 点「**加载解压缩的扩展**」→ 选上面那个文件夹。
3. 扩展出现在列表里即安装完成。建议点工具栏的拼图图标，把它「固定」到工具栏。

**升级到新版本**：解压覆盖原文件夹 → 回到 `edge://extensions/` → 点该扩展卡片上的「**刷新**」图标。网页需要 `F5` 刷新生效。

### 首次设置

首次安装会自动打开设置页：

1. 粘贴你自己的 DeepSeek API Key（`sk-` 开头，在 <https://platform.deepseek.com/api_keys> 生成）；
2. 把「**模型**」改为 `deepseek-flash`。v1.3.1 预填的 `deepseek-chat` 已停用，使用「恢复默认」后也需要重填。
3. 点「**测试连接**」，确认返回示例译文后点「**保存**」。[DeepSeek API 文档](https://api-docs.deepseek.com/en/)

> Key 保存在本机 `chrome.storage.local`，并作为认证凭据随请求发往所配置的 API 地址。默认是 `https://api.deepseek.com`。

## 三、网页翻译

### 3.1 整页中英对照

点页面右侧「**译**」圆钮，或工具栏图标 →「翻译此页」，或 `Alt`+`T`。

- 按**段落/标题/列表项/表格单元格/引用块**逐段翻译，译文插在原文下方，带一条淡蓝色竖条；
- **原文一个字符都不改**（不重排、不替换节点），所以链接、排版、字号都不会坏；
- 译文会继承原文的字体、字号、粗细、行高、对齐方式 —— 标题译文仍然像标题；
- 进度提示「正在翻译 12/48 段…」，完成后显示「翻译完成 · 48 段」。

### 3.2 仅译文 / 还原原文

- 想只看中文：工具栏图标 →「对照方式」选「**仅译文**」，原文会收起来；
- 想退回**看完原文、再点一次「译」就恢复对照**，译文缓存还在，不花钱重翻；
- 点「**恢复原文**」（或再点一次「译」按钮 / `Alt`+`T`）把页面还原成 100% 原样，随时可以再翻。

### 3.3 划词翻译

选中任意文字 → 浮出小「译」气泡 → 点它，弹出卡片显示译文（附原文、可复制）。按 `Esc` 关闭。

### 3.4 右键菜单

在网页任意处右键，有这几项：

- 「翻译选中内容」
- 「用 DeepSeek 整理这篇文献」
- 「整页翻译」
- 「恢复原文」

### 3.5 动态页面

无限滚动、SPA 路由切换、懒加载出来的新内容会**自动补翻**（页面变动后 700ms 防抖触发），不用手动重点。

### 3.6 什么不会翻（设计如此）

- `code` / `pre` / 输入框 / 脚本样式等标签内的内容 —— 代码和数字翻错比不翻更糟；
- 单段超过 **3000 字**的超长段落；
- 已经是目标语言的段落（按字符集比例判断，免得中文页再翻一遍）；
- 单页最多处理 **900 个块**，防止超大页面把 Key 打爆；
- 浏览器内部页（`edge://`、扩展商店、PDF 阅读器）不允许扩展注入脚本，这是浏览器限制，任何扩展都一样。

### 3.7 深色页面自动适配

深色导航栏/深色卡片上，如果原文颜色与背景对比度不够，译文会自动切成浅色字（`#e7ecf9`）并加一点半透明底色；浅色背景上则用深色字。

## 四、缓存与计费（重点）

**译文缓存在本地**，键 = 模型 + 目标语言 + 文本长度 + 文本哈希，落盘在 `chrome.storage.local`，最多 6000 条，超出按写入顺序淘汰最旧的。

所以下面这些情况**都是 0 次请求、0 费用**：

- 点「恢复原文」后再点「翻译」；
- 刷新页面（`F5`）后再翻同一页；
- 关掉浏览器、第二天打开再翻同一页；
- 重载扩展（刷新扩展）之后再翻同一页。

进度提示会直接写出来：「翻译完成 · 48 段（**48 段来自本地缓存，没花钱**）」。

> 会重新花钱的情况：网页内容变了（新闻列表刷新、论文页换了文章）、换了模型、换了目标语言、点面板里的「重新生成」（文献总结）。

## 五、文献整理（记笔记）

### 5.1 完整流程

1. 打开论文页面（IEEE Xplore / ScienceDirect / arXiv / Springer / 知网等，只要正文正常显示就行）。
2. 点右侧粉紫色的「**摘**」圆钮（或右键 →「用 DeepSeek 整理这篇文献」）。
3. 等十几秒 —— DeepSeek 把全文读一遍，整理成 8 个小节：

   | 小节 | 内容 |
   | --- | --- |
   | 一句话概括 | 这篇论文干了什么、结论是什么（一句话） |
   | 研究问题 | 针对什么痛点/空白 |
   | 研究思路 | 解决问题的技术路线 |
   | 研究方法 | 建模、实验、仿真、样机等具体手段 |
   | 主要内容 | 论文做了哪几件事 |
   | 主要结论 | 得到什么结果、量化结论 |
   | 关键数据 | 重要数字（效率、误差、功率、时间…） |
   | 局限与延伸 | 作者承认的局限、可延伸方向 |

4. **面板最上面就是「我的笔记」** —— 先写你自己的判断、想法、和哪篇文章有关。
5. 下面每一节都可以**直接点进去改字**（像编辑文档一样），标题右侧会从「AI」变成「已改」。
6. 不想要的小节**取消勾选**，导出的 md 里就不会有。
7. 面板底部「保存到」一行点「**选择文件夹**」，选一次总目录（以后一直用它）。
8. 点「**保存为 .md**」，文件立刻写进磁盘，面板底部回显完整路径。
9. 想先预览，点「复制 Markdown」粘到任何地方看看。

### 5.2 截图 / 图片

- `Win`+`Shift`+`S` 截完图，直接在面板里 `Ctrl`+`V` 粘贴；
- 也可以点「＋ 图片 / 截图」选文件，或把图片拖进面板；
- 缩略图右上角 `×` 删除；
- 保存时图片会**以 base64 直接内嵌进这一个 md 文件**（不生成 `images/` 目录），发给别人、换台电脑打开都能看到；
- 自动压缩：长边缩到 **1600px**、WebP q0.9（不支持时退 JPEG），一张典型截图 100~300KB；原图上限 8MB。

### 5.3 保存位置与目录命名

- 总目录：你自己选一次的那个文件夹（面板底部 / 设置页都能看到当前是哪个）；
- 每篇论文一个子目录，命名规则：**`年月日-期刊缩写-关键词`**
  例：`2026-11-12-IEEE TEC-构网型储能·数据中心`
- 文件：`2026-11-12 标题.md`
- 换文件夹：面板底部点「**更改**」。句柄按站点记，第一次在新站点保存会再问你一次，点一次就好。


### 5.5 自动草稿

改过的内容（含勾选状态、贴的图、自己写的笔记）会**按网址自动存草稿**，最多保留最近 30 篇。

- 下次打开同一篇文章点「摘」→ 直接恢复你改过的版本，**不会重新花钱跑一遍**；
- 想推倒重来：点面板里的「**重新生成**」（会重新请求，花钱）。

### 5.6 抓不到正文会明确告诉你

- 正文不足 **400 字**（比如搜索列表页）：提示「这一页没抓到足够的正文」，不会编造；
- 正文超过 **3.8 万字**：截断末尾再送模型（超长综述也能用，只是结尾可能没读到）。

## 六、侧边翻译框（查词 / 粘贴翻译）

点右侧「**文**」圆钮打开：

- 输入一个**单词** → 点「查词」→ 音标 + 词性 + 释义（多义项分行）；
- 粘贴一句/一段 → 点「翻译句子」→ 译文 + 术语对照表；
- 懒得选？直接按 `Ctrl`+`Enter`，自动判断是词还是句子；
- 结果右下角「复制」一键拿走；
- 打开面板时如果页面上正选着文字，会自动带进去作为输入；
- 单次上限 4000 字符。

## 七、设置项详解

工具栏图标 →「设置」打开。

| 设置 | 默认 | 说明 |
| --- | --- | --- |
| API Key | 空 | 自己填，`sk-` 开头；只存本机 |
| 接口地址 | `https://api.deepseek.com` | 一般不用改（有中转才改） |
| 模型 | v1.3.1 预填 `deepseek-chat` | 使用官方接口时，改填当前可用的 `deepseek-flash`。 |
| 目标语言 | 简体中文 | 支持中/英/日/韩/法/德/西/俄/葡/意/阿等 12 种 |
| 对照方式 | 中英对照 | 或「仅译文」 |
| 悬浮按钮 | 开启 | 关掉后页面右侧不再显示三个圆钮（右键菜单和快捷键照样可用） |
| 每批段落数 | **30** | 一次请求打包多少段；越大请求次数越少、越省钱 |
| 每批字符数 | **6000** | 一次请求最多多少字符 |
| 并发请求数 | 3 | 遇到 429 调小到 1~2 |

页面上还有：

- 「测试连接」：真发一条请求，回显延迟 + 示例译文；
- 「恢复默认」：保留你的 API Key，其余重置；
- 「文献笔记」卡片：显示当前选择的保存文件夹 + 「打开笔记页」按钮。

## 八、费用与省钱

以下为原版说明记录的历史实测与估算，使用当时的 `deepseek-chat` 报价。当前费用按实际使用的模型和 token 用量计费。[DeepSeek 计价](https://api-docs.deepseek.com/quick_start/pricing/)

| 场景 | 请求数 | 输入 tok | 输出 tok | 约 |
| --- | --- | --- | --- | --- |
| 10,143 字符论文页（默认 30 段 / 6000 字符） | 2 | 2376 | 1757 | **¥0.018** |
| 同上，小批次 20 段 / 2200 字符 | 5 | 3060 | 1837 | ¥0.021 |
| 一次文献整理（论文全文 1 万字） | 1 | ~900 | ~700 | **¥0.008** |

- 换算：**每千字符约 ¥0.002**，5 分钱 ≈ 两万五千字符（一篇 IEEE 全文的量）；
- 钱主要花在**输出 token**（占约 2/3）—— 翻多少字基本就是多少钱，这是模型成本，不是扩展乱发请求；
- 最有效的省钱手段：① 批次调大（默认已是 30/6000）；② 同一页别反复重翻（缓存本来就免费）；③ 别整页翻参考文献/Related Articles。

## 九、常见问题

**Q：提示 401？**
API Key 无效或已失效。去设置页换一个新的，点「测试连接」确认。

**Q：提示 402？**
DeepSeek 账户余额不足，去开放平台充值。

**Q：提示 429？**
请求太密（并发太高）。把「并发请求数」调成 1~2，再试。

**Q：某些页面点翻译没反应？**
`edge://`、扩展商店、PDF 阅读器等浏览器内部页面不允许注入脚本。本地 `file://` 页面需要在扩展详情里打开「允许访问文件网址」。

**Q：个别段落没翻？**
超过 3000 字的超长段落、`code/pre` 里的内容、已经是中文的段落，按设计跳过。

**Q：还原原文后再翻译还会花钱吗？**
不会。缓存已持久化（v1.3.1 起），进度提示会显示「N 段来自本地缓存，没花钱」。只有网页内容本身变了才会重新请求。

**Q：换了模型/目标语言要重翻吗？**
要，缓存键包含模型和目标语言，属于不同结果。

**Q：md 里的图片看不到了？**
图片是 base64 内嵌的，正常用 VS Code / Typora / Obsidian 打开都能显示。如果编辑器把 base64 显示成乱码一行，换成「预览模式」看。

**Q：换电脑后要重新选文件夹？**
目录句柄是按站点存在浏览器里的，新环境第一次保存会再问你一次，点一次即可。

**Q：能给别的浏览器用吗？**
Chrome / Edge / 基于 Chromium 的浏览器（版本 ≥ 102）都行，`chrome://extensions` 加载方式一样。

## 十、隐私与安全

- **默认直连 DeepSeek**。任务所需的网页文本发往设置中的 API 地址。
- **使用自备 Key**。Key 通过 `chrome.storage.local` 保存在本机，发出 API 请求时用作认证凭据。
- **笔记只写你选的文件夹**：用浏览器 File System Access API 直接落盘，不经过网络；
- **草稿存在本机**：`chrome.storage.local`，最多 30 篇，可在笔记面板里覆盖或清空；
- 扩展申请的权限：`storage`（存设置/缓存/草稿）、`contextMenus`（右键菜单）、`activeTab` + `scripting`（注入脚本）、`downloads`（无文件夹权限时的下载兜底）、`unlimitedStorage`（缓存与截图草稿）、以及仅限 `api.deepseek.com` 的 host 权限。

几个关键设计：

- **翻译请求必须走 service worker**：内容脚本受 CORS 限制，不能直接调 DeepSeek。
- **不替换原节点**：译文是独立 `div` 插在原文后面，所以还原是无损的；`position:static !important` 等属性把它强制从浮层里拉回文档流，避免 IEEE 那种绝对定位格子里叠字。
- **提示词强制 JSON**：`{"translations":[...]}` 且要求条数与输入一致，条数不符先严格重试、再对半拆分重发，最后仍失败就保留原文。
- **缓存键带模型与语言**：换模型/换语言不会误用旧译文。
- **文献总结单独一套提示词**：要求只依据正文、不编造、缺失就留空（比如页面没有 DOI 就输出空串，宁可空着也不瞎填）。
