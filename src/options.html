保存文件夹 在文章页点「摘」整理完，面板底部就能选或换文件夹 未选择

保存位置直接在那个「文献总结」面板里设置：点「选择文件夹」选一次，之后一直用它；想换点「更改」即可，不会再跳到别的页面。

怎么用：打开任意网页 → 点工具栏上的扩展图标 → 「翻译此页」；或直接按 Alt+T。选中文字会浮出「译」按钮，右键菜单也可以。

费用：整页翻译是按实际消耗的 token 计费，一篇长文通常几分钱。相同段落会被缓存，重复翻译同一页几乎不花钱。

隐私：只把你正在看的网页文字发给 DeepSeek 官方接口，API Key 存在浏览器的 chrome.storage.local 里。
